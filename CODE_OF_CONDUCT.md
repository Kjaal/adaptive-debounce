# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate. Harassment, discrimination, threats, and publishing
another person's private information are not acceptable in project spaces.

For conduct concerns, contact the maintainer through GitHub at [@Kjaal](https://github.com/Kjaal).
Repository matters should go through this repository's [GitHub Issues](https://github.com/Kjaal/adaptive-debounce/issues).
Do not place sensitive details in a public issue. For violations of GitHub platform policies, use
GitHub's native Report Abuse function. Maintainers may remove content or restrict participation
when needed to protect the community.
