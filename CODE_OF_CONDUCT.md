# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate. Harassment, discrimination, threats, and publishing
another person's private information are not acceptable in project spaces.

When the repository is hosted, report conduct concerns through the private maintainer contact shown
there. Do not place sensitive conduct reports in public issues. Maintainers may remove content or
restrict participation when needed to protect the community.
